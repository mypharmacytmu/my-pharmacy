# My Pharmacy v25 技術需求

Phase 1 以 `mypharmacytmu/my-pharmacy` 的 `main`（`8961e54`）為基準。此文件區分已確認的產品需求與後續須審查的實作提案。Phase 1 交付既有畫面的返回修復、回歸測試、資料設計及 2D 平面圖。

## 使用流程

- **模式 A｜自由規劃**：保留新增、編輯、搜尋、刪除藥品，商品名、劑量、劑型、包裝及圖像設定，個人目錄與代碼進貨，建立及管理藥架，3D 總覽／獨立藥架、上架／替換／移除、重置、短暫體驗、唯讀 HTML 成果分享。獨立藥架須在桌面、平板、手機提供滑鼠及觸控可用的返回總覽，保留已上架內容及旋轉、縮放、平移、恢復預設視角。
- **模式 B｜營業模擬**：選個人藥局或輸入教師代碼 → 輸入姓名 → 逐題讀案例、在 3D 藥局選藥 → 提交並計分 → 下一位客人 → 總成績、PNG 與當次檢討。教師藥局、配置、案例及評分唯讀，作答放在個別工作階段。個人藥局可回模式 A 編輯。
- 提交前能新增、移除、更換及檢查藥品組合。只在正式提交時計分，提交後答案不可編輯。同場無暫停，每題獨立計時，案例不得重複。

## 場景與教師資料

方案 C 是 L 型櫃檯與開放陳列，5 座 OTC、3 座 RX。保留白色與醫療綠、3D 架位及點選。入口、等候區、櫃檯、OTC、處方藥和調劑區須易辨識。OTC 架避開櫃檯主要視線與動線，可擴大現行 9 × 7 m。圖面座標與實際布局須先核准。

藥品沿用學名、劑量、劑型的既有重複規則及已發布資料。新增多選適應症標籤、單一藥理分類、孕婦用藥狀態。標籤與分類由老師維護穩定 ID，案例引用同一 ID。正式比對採 ID；無文字模糊匹配、臨時推測或跨類別過敏推導。孕婦狀態有可用、禁用、需評估、未知，懷孕案例只有審核為可用才通過。標記僅對教師審核的教材條件有意義，不能泛化到不同孕期、劑量或臨床情境。舊資料缺欄不得默認可用。

管理端保留既有功能，後續支援網頁逐筆編輯與 Excel 批次匯入藥品及案例、標籤與分類維護。「驗證並匯出發布包」支援一般藥品包及單一代碼載入的「已上架藥局＋案例＋評分設定」。案例由教師建立、審核、發布，含識別、名稱、題型、題幹或處方、解析、目標時間、需求、過敏、孕況、上限、個人練習開關和題型規則，僅使用適用欄位。

## 案例與評分

| 項目 | 已確認規則 |
|---|---|
| 處方箋 | 藥品、劑量、劑型全部正確才有 100% 準確率，任一錯誤為 0%。無數量評分、無欄位部分分。等價答案及複方須另確認。 |
| OTC | 不重複選同一藥品，可多選並由教師設定不同品項上限。先排除與過敏分類相同或在指定懷孕時未標為可用的藥品，再取合法藥品涵蓋需求標籤的聯集。基礎準確率為涵蓋的不同需求標籤數除以需求總數，乘 100。 |
| 額外推銷 | 每個無助於需求的額外品項扣單題準確率 10 個百分點，下限為 0%。其餘合法藥仍可得涵蓋分。重疊標籤、違反安全條件及超上限的細節待審。可顯示「這間藥局會亂推銷！」。 |
| 計時與單題分數 | 目標秒數 T > 0。若 t ≤ T，速度 20 分；否則為 20 × max(0, 1 − (t − T) / T)。單題為準確率百分數 × 0.8 + 速度分，滿分 100，不分階扣速。例：超時 15% 時速度 17 分。 |
| 全場 | 加總各題，呈現各題得分、原始總得分、實際滿分、百分制、整體準確率及全場時間。保留預定與實際題數、調整原因。 |

教師藥局可指定題庫及兩種題型各抽幾題，或指定本場固定案例後隨機排列，兩者皆不重複。個人只抽教師明確開放的常見練習案例，通常只抽目前可完成的題目，題數不足可降低並註明。若確有完整可行解，「抱歉，這個我們藥局沒有賣」的準確率為 0%；只有確實無解才答對。該操作超過兩次顯示「你的藥局好像什麼都沒賣！」，無解題來源與計分見待確認清單。

## 成績、隱私與驗收

- PNG 含 My Pharmacy、姓名、日期、原始得分、滿分、百分制、整體準確率、時間、實際題數及減題原因。檢討頁含題目、提交答案、答案或條件、藥品涵蓋、需求缺口、安全限制、額外推銷、準確率／時間／速度分及教師解析。PNG 無互動功能。
- 不登入或建立學生帳號。姓名、答案及成績留在瀏覽器，PNG 於本機生成。不自動上傳 GitHub；瀏覽器成績可被竄改，不具正式監考效力。
- GitHub Pages + Actions，保留 AP4444、AP5555、DAPA22、TEST66 等舊包、圖片、版本及既有成果。發版以最新 main 索引合併，驗證代碼唯一、合法路徑、不可變歷史、新版本的案例／標籤／藥品／場景位置／圖片參照。
- 後續進行 80 個並行瀏覽器工作階段測試。分開量測冷／熱載入、相同代碼、資料／圖片請求失敗率、資源及流量、3D、作答、計分與 PNG；實際電腦／平板測互動及效能。HTTP 壓測結果與實體裝置結果分開記錄，效能門檻待確認。
