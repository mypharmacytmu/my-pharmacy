# v25 待確認決策

以下需使用者或藥學教師審核。Phase 1 不採用這些待議規則。

| 待決事項 | 需定案的內容 |
|---|---|
| 配置 | 邊界、入口、櫃檯座標、走道、淨距、員工入口與相機方向；用樣機驗證視線、多人通行、調劑區和門扇。 |
| 適應症與分類 | 正式 ID、雙語名稱、症狀與適應症是否分開、拆分／合併、退役策略、藥品對應及教學提醒。舊分類自由文字須由教師映射。 |
| 新欄位相容 | 缺值與舊資料的唯讀映射、新模式對無標籤／無分類藥品的處理、未知病患孕況與安全規則適用哪些題型、版本索引及舊成果載入策略。 |
| 處方等價 | 多藥處方、同義品項、複方、可替代品、答案集合與既有識別鍵如何對應。 |
| OTC 額外推銷 | 重疊標籤的冗餘判定是否採唯一貢獻或最小涵蓋集合，如何避免依選取順序；安全違規品項是否也扣推銷，超過品項上限時阻擋還是按規則判分。 |
| 無法供應 | 怎麼安排可合理無解的題；正確回答的準確率與速度分；判定有解是否納入上限／懷孕／過敏；零題可完成是否允許開始。 |
| 題庫不足 | 教師指定題數超過合格題庫時的錯誤／調整策略，個人練習減題時如何維持題型配比。 |
| 計時與顯示 | 每題計時起點、轉場排除、背景分頁和裝置休眠策略、整體準確率加權、四捨五入精度及分數加總順序。 |
| Excel | 檔案欄名、型別、必填、可接受空白、資料重複、圖片交換、覆蓋與失敗策略、跨表鍵與填寫教學。 |
| UI 與成果 | 新模式入口、候選藥品的選取及提交提示、空狀態、姓名與 PNG 版面、全場檢討和下載行為。 |
| 效能 | 並行負載基準、網路條件、設備組合、讀取時間與記憶體、影格率目標。 |

建議依序審核平面座標、資料及詞彙、計分邊界與使用流程。確認後才更新正式 schema、選題／計分測試及場景。
